# Hooksmith CLI

Command-line and GitHub Action distribution for [Hooksmith](https://github.com/Kralizek/hooksmith).

This repository owns the `@hooksmith/cli` package and the GitHub Action that runs it. Hooksmith runtime libraries and built-in extensions remain in the main Hooksmith repository.

## Packages

- [`@hooksmith/cli`](./packages/cli)

## GitHub Action

The repository root contains `action.yml`, keeping the Action and CLI distribution together.

Release orchestration is intentionally not part of the initial repository move and will be designed separately.
